## How to test UI changes safely

The browser dev server (`pnpm --dir app dev`, port 1420) reads and writes the
real `artifacts/phase3/active-project`. To test empty, stale, or destructive
flows, run a second Vite from a scratch copy:

```sh
S=/tmp/drive16-scratch-$(date +%s); mkdir -p $S
rsync -a --exclude node_modules --exclude dist app/ $S/app/
ln -s "$PWD/app/node_modules" $S/app/node_modules
for d in examples assets scripts agent corpus mcp-servers opencode.json; do ln -s "$PWD/$d" $S/$d; done
(cd $S/app && npx vite --host 127.0.0.1 --port 1421)
```

After `app/src` changes, keep these green: `pnpm --dir app build`,
`verify:agent-contract`, `verify:prompt-intent`, `verify:agent-watchdog`,
`verify:project-memory`.
